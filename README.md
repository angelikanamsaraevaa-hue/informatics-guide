\# Информатика для первокурсника

\## Цель проекта

Создание краткого справочника по информатике для студентов первого курса.

\## Автор

Angelika

\## Выбранная тема

Системы счисления.

\## Содержание проекта

* README.md — описание проекта.
* glossary.md — основные термины и определения.
* examples.md — примеры решения задач.
* sources.md — используемые источники информации.
* questions.md — вопросы для самопроверки.

\## Как пользоваться справочником

1. Изучите термины в glossary.md.

2\. Ознакомьтесь с примерами в examples.md.

3\. Изучите источники в sources.md.

4\. Проверьте знания с помощью questions.md.
