1. Система счисления - способ записи чисел с помощью определенных символов.
2. Основание системы — число различных значений цифр в этой системе. Для основания b используют b значений — от 0 до b−1; например, в шестнадцатеричной системе значения 10–15 обозначают буквами A–F.
3. Двоичная система - система счисления с основанием 2.
4. Десятичная система - система счисления с основанием 10.
5. Восьмеричная система - система счисления с основанием 8.
6. Шестнадцатеричная система - система счисления с основанием 16.
7. Разряд — место одной цифры в позиционной записи числа. В целой части разряды нумеруют справа налево, начиная с нуля; значение цифры равно её значению, умноженному на основание в степени номера разряда.
8. Бит - минимальная единица информации.
9. Позиционная запись — способ записи, при котором значение цифры зависит от её места. Например, 101₂ = 1×2² + 0×2¹ + 1×2⁰ = 5₁₀.
